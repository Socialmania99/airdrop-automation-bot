Airdrop Automation Bot v2.0

Track, analyze, and automate airdrop-eligible tasks across crypto projects. Powered by Claude AI, real web scraping, APScheduler, and Telegram/Discord alerts.

Philosophy: 3–5 wallets with genuine activity beats thousands of flagged bot wallets. This tool keeps you organized, early, and consistent.

Architecture

React 18 (Vite) ──► Flask REST API (:5050)
                          │
              ┌───────────┴────────────┐
         SQLite DB            Claude AI Analysis
                          │
              APScheduler (24h auto-run)
                          │
         Telegram / Discord notifications

Quick Start

  1. Step 1: Extract the ZIP to any folder
  2. Step 2: Copy backend/.env.example → .env and add API keys
  3. Step 3: Windows: double-click start.bat | Mac/Linux: ./start.sh
  4. Step 4: Open http://localhost:3000
  5. Step 5: Settings → enter Anthropic API key
  6. Step 6: Projects → Add Project → paste any crypto project URL
Works without an API key using rule-based fallback. Add your Anthropic key for AI-powered task generation.

Best Practices

  • 3–5 wallets with genuine on-chain history
  • Different seed phrases, stored securely offline
  • Fund each with small real amounts for gas
  • Separate browser profiles per wallet
  • Avoid bulk creation — Sybil detection is advanced in 2026

FAQ

Is this safe?
Yes. Public addresses only. No on-chain actions automated. All signing is manual.
Will I get flagged?
No — the bot tracks and reminds. You execute swaps manually. Genuine activity is the goal.
Do I need an Anthropic key?
No. Rule-based fallback works without it. With it, task generation is far more accurate.
How many wallets?
3–5 with genuine activity. Mass wallet farming is heavily penalized in 2026.
Where is data stored?
Locally in data/projects.db (SQLite). Nothing leaves your machine except optional Anthropic API calls.
Backend won't start?
Check Python 3.9+, venv active, requirements installed, port 5050 free.
